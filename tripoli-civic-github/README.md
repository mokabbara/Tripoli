# مجلس طرابلس المدني والمرصد البلدي

نسخة عربية تفاعلية من المقترح التأسيسي، مجهّزة للنشر مباشرة عبر GitHub Pages.

## النشر على GitHub Pages

1. أنشئ مستودعاً جديداً على GitHub.
2. ارفع `index.html` ومجلد `assets` وملف `.nojekyll` إلى جذر المستودع.
3. افتح **Settings → Pages**.
4. تحت **Build and deployment** اختر **Deploy from a branch**.
5. اختر فرع `main` والمجلد `/ (root)` ثم اضغط **Save**.
6. بعد دقائق سيظهر رابط الصفحة في قسم GitHub Pages.

يجب إبقاء أسماء الملفات وبنية مجلد `assets` كما هي حتى تظهر الصور والخطوط بصورة صحيحة.

## ملاحظات

- لا يحتاج الموقع إلى قاعدة بيانات أو عملية بناء.
- تعمل قائمة الإنجاز محلياً في متصفح كل مستخدم.
- تتضمن الصفحة نسب الصور وتراخيصها في قسم «مصادر الصور وحقوق الاستخدام».
- زر الطباعة يسمح بحفظ المقترح كملف PDF متعدد الصفحات.
